5执行

普通安装：只执行 adb install -r，不卸载旧包、不推送 fsa、不 root、不连 WiFi、不设默认桌面、不重启。 勾选「授予权限」时，安装成功后再静默授权：pm grant 运行时权限（含存储读写/媒体读取）+ appops 所有文件访问/悬浮窗/通知 + 电池白名单（不设 home）；取消勾选则只装软件。 需要完整配置请用左边的「并行安装」。
